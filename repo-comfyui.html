Core Subsystems Breakdown

ComfyUI treats diffusion generation as an asynchronous Directed Acyclic Graph (DAG), enabling granular execution, smart node caching, and minimal VRAM spikes:

01 • Engine

Graph Execution & Queue

Topological graph resolution, execution caching of unchanged nodes, and thread-safe prompt queueing for high-throughput pipeline workflows.

  • execution.py Graph Engine
  • main.py Runtime Worker
  • nodes.py Node Catalog
02 • Samplers

Model & VRAM Runtime

Intelligent model loading and offloading across GPU VRAM and system RAM, multi-architecture detection (Flux, SD, SDXL, HunyuanVideo), and K-diffusion samplers.

  • samplers.py Sampling Engine
  • model_management.py VRAM Manager
  • folder_paths.py Model Paths
03 • Interface

Prompt Server & User Files

AIOHTTP-powered asynchronous WebSocket server streaming live progress, preview latents, node highlights, and user file persistence.

  • server.py Prompt Server
  • user_manager.py User Files
  • model_manager.py Model Browser
04 • Extensions

Custom Nodes & Subgraphs

Dynamic Python plugin system allowing developers to register custom node classes, reusable nested subgraphs, and external API connectors.

  • custom_node_manager.py Plugin Manager
  • subgraph_manager.py Subgraphs
  • comfy_extras Built-in Extras

Quick Start & Headless API

PYTHON HEADLESS EXECUTION 
# Run ComfyUI server accessible on local network
python main.py --listen 0.0.0.0 --port 8188

# For systems with high VRAM, enable high performance mode:
python main.py --gpu-only --highvram
