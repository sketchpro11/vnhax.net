Core Subsystems Breakdown

LangChain is composed of modular packages (`langchain-core`, `langchain`, and partner libraries) designed for composability and streaming execution:

01 • LCEL

Runnables & Agent Execution

LangChain Expression Language (LCEL) provides unified asynchronous streaming, batching, parallel execution, and tool-calling agent loops.

  • runnables/base.py Pipelines
  • agents.py Agent Runner
  • tools/base.py Tool Protocol
02 • Prompts

Model Generation & Parsers

Type-safe prompt templating, multi-modal message representations, unified LLM client interfaces, and structured output schema parsers.

  • prompts/base.py Prompt Engine
  • language_models/base.py LLM Base
  • output_parsers/base.py Parsers
03 • RAG

Retrieval & Vector Stores

End-to-end document indexing pipeline: text chunkers, embedding models, vector store abstractions, and context retrieval strategies.

  • retrievers.py Retrievers
  • vectorstores/base.py Vector Stores
  • embeddings.py Embeddings
04 • Ops

Callbacks & LangSmith Tracing

Hook-based event listeners streaming execution metrics, token counts, latency tracking, and cloud telemetry export to LangSmith.

  • callbacks/manager.py Callback Manager
  • tracers/context.py Tracing
  • _sql_record_manager.py Record Store

Quick Start: LCEL Chain

PYTHON LCEL EXAMPLE 
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# Pipe syntax constructs an LCEL Runnable pipeline
prompt = ChatPromptTemplate.from_template("Explain {topic} in simple terms")
model = ChatOpenAI(model="gpt-4o")
chain = prompt | model | StrOutputParser()

# Invoke synchronously or stream tokens in real time
response = chain.invoke({"topic": "vector databases"})
print(response)
