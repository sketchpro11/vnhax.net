Core Subsystems Breakdown

Aider combines interactive terminal I/O with deep Git worktree integration and Tree-sitter code graphing:

01 • Repo Map

Tree-Sitter Code Graph

Constructs a compact AST symbol graph of your entire Git repository using Tree-sitter queries and PageRank to supply relevant context without overflowing tokens.

  • repomap.py Repo Map
  • python-tags.scm Tree-Sitter Tags
  • repo.py Git Boundary
02 • Protocols

Edit Protocols & Lint Repair

Multi-strategy edit application (Search/Replace blocks, unified diffs, whole-file rewrite) backed by automatic linter validation and repair feedback loops.

  • editblock_coder.py Edit Protocol
  • diffs.py Diff Handler
  • linter.py Linter Runner
03 • Session

Terminal I/O & Command Dispatch

Prompt toolkit powered terminal interface with autocomplete, chat history persistence, multi-line editing, and voice/image input support.

  • io.py Terminal I/O
  • commands.py Commands
  • history.py Chat History
04 • Routing

Multi-Model LLM Routing

Supports Claude 3.5 Sonnet, GPT-4o, DeepSeek, and local Ollama models with automatic benchmark-tuned settings and cost analytics.

  • llm.py LLM Runtime
  • sendchat.py Streaming Transport
  • models.py Model Resolution

Quick Start & CLI Options

LAUNCH WITH CLAUDE OR LOCAL OLLAMA 
# Pair program with Anthropic Claude 3.5 Sonnet
export ANTHROPIC_API_KEY=your-key
aider --model claude-3-5-sonnet-20241022

# Or pair program with local Ollama models (100% private)
aider --model ollama/deepseek-coder-v2
