Core Subsystems Breakdown

Cline separates UI presentation from execution via a high-performance gRPC hostbridge, granting secure tool invocation:

01 • Hostbridge

gRPC & Protobus Bridge

Decoupled communication layer bridging VS Code extension host APIs or standalone Go CLI processes with the core TypeScript execution engine.

  • hostbridge-grpc-service.ts gRPC Server
  • protobus-service.ts Protobus
  • controller Task Controller
02 • Tools

MCP Protocol & Checkpoints

Standard Model Context Protocol client allowing users to plug in arbitrary tool servers, alongside disk snapshot rollback checkpoints for safety.

  • services/mcp MCP Protocol
  • checkpoints State Snapshots
  • terminal Shell Execution
03 • Webview

React Webview UI

A reactive sidebar interface showing real-time token counts, unified file diffs, command approval dialogs, and browser previews.

  • main.tsx Webview Entry
  • webview-ui/src React Components
  • hosts/vscode Host Integration
04 • CLI

Go CLI & SQLite History

Headless and terminal-based agent frontend in Go, writing command execution history, session tokens, and logs to local SQLite storage.

  • cmd/cline Go CLI Binary
  • sqlite Session DB
  • browser Puppeteer Service
