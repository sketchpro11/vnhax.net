Open-Source Repository C/C++ Inference Core
ggml-org / llama.cpp GitHub Repo ↗

High-performance LLM inference in pure C/C++ with minimal dependencies. Powers local AI runtimes (including Ollama), featuring GGUF quantization, multi-backend acceleration (CUDA, Metal, CPU, Hexagon), and OpenAI-compatible server APIs.

Core Subsystems Breakdown

llama.cpp structures its operations into modular layers allowing execution on everything from Raspberry Pi CPUs to massive multi-GPU clusters:

01 • Compute

Inference & GGML Graph

Constructs dynamic computation graphs via GGML, enforces strict grammar sampling constraints, and orchestrates tensor evaluation.

  • common.cpp Inference Runtime
  • ggml-backend.cpp GGML Graph
  • chat.cpp Prompt Grammar
02 • Hardware

Hardware Acceleration

A unified backend registry dynamically selects optimized compute kernels: AVX2/AVX-512 CPU routines, CUDA kernels, or Qualcomm Hexagon DSPs.

  • ggml-backend-reg.cpp Registry
  • ggml-cpu.cpp CPU Backend
  • ggml-quants.c Quantization
03 • Serving

Serving & MCP Layer

Production HTTP web server supporting continuous batching, streaming SSE responses, OpenAI API parity, and Model Context Protocol (MCP) tools.

  • server.cpp HTTP Server
  • cli-client.cpp CLI Client
  • chat.service.ts Web Chat
04 • Models

Model Lifecycle & GGUF

Standardized GGUF binary format specifications, Hugging Face Hub caching, and conversion scripts transforming raw PyTorch weights into quantized formats.

  • gguf.h GGUF Format
  • hf-cache.cpp Cache Store
  • base.py Converter

Quick Start & Usage

RUN INFERENCE 
# Interactive conversational mode
./llama-cli -m models/llama-3.3-8b.gguf -p "You are a helpful assistant" -cnv

# Start OpenAI-compatible HTTP server
./llama-server -m models/llama-3.3-8b.gguf --port 8080
